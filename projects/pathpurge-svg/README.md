# PathPurge SVG

## Problem
Exported SVGs are often bloated with redundant commands and excessive decimal precision, making them heavy and hard to manage.

## Features
- Interactive SVG path rendering.
- Real-time decimal precision rounding.
- Absolute to Relative command conversion.
- Local-first: No data leaves your browser.

## Usage
1. Open `index.html` in any modern browser.
2. Paste your SVG `<path>` data (the 'd' attribute) into the input.
3. Adjust the precision slider to see the visual impact.
4. Copy the optimized code from the output area.

## Privacy
This application runs entirely in your browser. No data is sent to any server.
